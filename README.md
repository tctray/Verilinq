## VeriLinq

VeriLinq is a fast, private, local-first desktop application that scans websites for broken links in seconds, helping keep content reliable and user-ready.


<p align="center">
  <img src="src/assets/desktop.png" alt="VeriLinq Logo" width="50%">
</p>

## Why VeriLinq
Content-heavy websites naturally accumulate broken links over time due to redesigns, removed pages, and outdated documents. VeriLinq helps identify these issues quickly before they affect users or trust.

## Features
- Scan webpages for broken links
- Clear pass/fail status indicators
- Summary of valid vs broken links
- Local-first (no cloud, no data upload)
- Desktop-focused workflow

## Built With
- Tauri (desktop application framework)
- Rust (backend link scanning)
- HTML, CSS, JavaScript (frontend UI)

## Status
VeriLinq is an actively evolving project.
